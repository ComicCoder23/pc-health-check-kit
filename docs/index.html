PC Health Check Kit

I fixed my mum's slow PC by hand, then wrote PowerShell checks that inspect and report without changing existing files. The checks write plain-text reports to the Desktop. Not yet run on another PC.

View on GitHub Download the pack See the scripts

Audit first

Scripts read and report only. Cleaning happens after evidence, never as a blind sweep.

Safe by default

No system folders. Obvious junk only. If unsure, leave it and write it in the session notes.

Visit-shaped

Master Index → Quick Run Card → ask → DiskSpace + Downloads → clean → notes. Optional scripts only if still needed.

Script run order

#ScriptPurpose
1DiskSpaceAudit.ps1Always first — drive space and user folder sizes
2DownloadsAudit.ps1Usual second — large/old downloads and installer clutter
3LargeFilesFinder.ps1Only if space is still tight or unexplained
4InstalledProgramsExport.ps1Only if apps review is needed
5StartupItemsReview.ps1Only if startup is still sluggish

Safety: scripts do not delete, move, or modify user files. They write one plain-text report to the Desktop. Do not approve unexpected administrator prompts.

Quick visit flow

  • Open Master Index → Quick Run Card → Safety Notes
  • Ask the opening questions
  • Run DiskSpaceAudit then DownloadsAudit
  • Clean obvious Downloads junk and Desktop clutter
  • Empty Recycle Bin · recheck free space · update Session Notes
  • Only if still needed: LargeFilesFinder → Programs Export → Startup Review
