Ask before changing anything. Audit first. If unsure, leave the item alone and
record it in the session notes. Reports and completed notes can contain personal
information; keep them private and review them before sharing.

The scripts in `../04 Scripts/` run only when the PC owner/helper chooses to run
them, with `ReportPrivacy.ps1` kept beside them. Use DiskSpaceAudit.ps1 first,
DownloadsAudit.ps1 second; LargeFilesFinder.ps1, InstalledProgramsExport.ps1 and
StartupItemsReview.ps1 are optional when the earlier checks justify them.
